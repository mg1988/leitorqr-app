## 五、审核与合规红线

1. **不能写「免费试用」**——在售只有买断（另有已下架的 7 天体验卡），App Store 的免费试用只属于自动续期订阅。描述里已全部避开。
2. **不能提 PIX**。竞品把商品码/PIX 当卖点，我们的 `EPC` 解析器只认 `BCD` 开头的欧洲付款码，巴西 PIX 的 BR Code（`000201`）会被当普通文本显示。写进元数据属于功能不符，有被拒风险。
3. **不能写比价 / 查配料表**。我们没有商品库，这是竞品的护城河，不跟。
4. **描述里的条码清单必须与代码一致**：读 9 种（QR / Aztec / PDF417 / Data Matrix / Code 128 / Code 39 / EAN-13 / EAN-8 / UPC-E），生成 7 种。描述只承诺了读的能力，没有说生成 9 种。
5. **隐私表述要能被隐私清单佐证**：`PrivacyInfo.xcprivacy` 里 `NSPrivacyTracking=false`、`NSPrivacyCollectedDataTypes=[]`，与「无追踪、无账号、数据不出设备」一致。
6. **链接政策页要能打开**：`https://mg1988.github.io/leitorqr-privacy/` 已上线（GitHub Pages）。
